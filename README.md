## 📌 Overview

**Financial Performance & Business Operations Analytics** is an end-to-end financial analytics project that transforms company financial data obtained through an API into structured, analysis-ready datasets and presents the results through an interactive Streamlit dashboard.

The project combines:

- API-based financial data collection
- Raw JSON data storage
- Data processing and transformation
- Structured CSV datasets
- PostgreSQL database
- SQL-based analysis
- Python-based financial analysis
- Interactive Streamlit dashboard
- Financial KPI analysis
- Multi-company comparison
- Historical trend analysis
- Predefined financial insights

The dashboard currently analyzes:

- Apple (AAPL)
- Amazon (AMZN)
- IBM (IBM)
- JPMorgan Chase (JPM)
- Microsoft (MSFT)

---

## 🎯 Project Objectives

The main objectives of this project are to:

1. Collect company financial statement data through an API.
2. Preserve the original API responses as raw data.
3. Clean and transform financial data into structured datasets.
4. Store processed financial metrics in PostgreSQL.
5. Query financial data using SQL.
6. Build an interactive financial analytics dashboard.
7. Compare companies across important financial indicators.
8. Analyze historical financial trends.
9. Identify financial strengths and potential risks.
10. Present the results in an analyst-friendly format.
